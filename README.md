# ХОЛОС: ЯДРО 8

Пиксельный браузерный платформер. Без движка и сборки: `index.html` + Canvas 2D.

## Запуск

Открой `index.html` в браузере или включи GitHub Pages (Settings → Pages → ветка `main`, папка `/`).

## Управление

- ← → или A/D — бежать
- ↑, W, Z или пробел — прыжок
- На телефоне — кнопки на экране

## Что внутри

- Капча «Я не холос» на старте
- Уровни 1–3 Одесса, 4–6 Газа, 7–9 Израиль
- Уровень 10 — босс МрДрНос в мета-пространстве (бей его царь-флешками)
- Секретный уровень 11 — Солевая шахта (вход спрятан на уровне 8)
- Бутылки Никиты Яроша снимают сердце, Дынекс убивает сразу, флешки лечат
- Прогресс сохраняется в браузере

## Файлы

- `sprites.js` — спрайты в виде текстовых карт, один символ = один пиксель
- `game.js` — движок, генератор уровней (`buildLevel`), боссы, сюжет и концовки
